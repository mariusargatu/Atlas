# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep disagreement about the work rather than about the person doing it. Harassment of any kind is not acceptable here.

This repository is largely about telling people their numbers do not mean what they think they mean, so one thing is worth saying out loud. Criticism of a measurement, an argument or a piece of code is welcome, and the sharper the better. It stays welcome as long as it is aimed at the claim. Being right is not a licence to be unpleasant to whoever was wrong, and quite a lot of what is written down here is the author having been wrong.

Report unacceptable behaviour to contact@mariusargatu.com. Reports are handled privately.
